# سجل البكش

نظام تتبع حركة أقفاص السمك (البكش) بين المخزن والمزارع والمبايع. يعمل بالكامل داخل المتصفح بدون إنترنت وبدون خادم، والبيانات محفوظة على الهاتف نفسه.

---

## الملفات المطلوبة

ارفع هذه الملفات **الستة** وهي كل ما يحتاجه أندرويد:

| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كله |
| `manifest.webmanifest` | يجعله قابلًا للتثبيت كتطبيق |
| `sw.js` | التشغيل بدون إنترنت |
| `icon-192.png` | الأيقونة الصغيرة |
| `icon-512.png` | الأيقونة الكبيرة |
| `icon-maskable-512.png` | أيقونة الشاشة الرئيسية في أندرويد |

ملفان إضافيان اختياريان: `favicon.png` (أيقونة تبويب المتصفح) و`apple-touch-icon.png` (للآيفون فقط). ارفعهما إن أردت، وغيابهما لا يعطّل شيئًا.

**مهم:** كل الملفات في جذر المستودع مباشرة، بدون مجلد يحتويها، وبنفس الأسماء حرفًا بحرف.

---

## أولًا: إنشاء المستودع على GitHub

1. من متصفح الهاتف أو الكمبيوتر ادخل [github.com](https://github.com) وسجّل الدخول (أنشئ حسابًا مجانيًا إن لم يكن لديك).
2. اضغط **+** أعلى اليمين ← **New repository**.
3. في *Repository name* اكتب: `baksha`
4. اختر **Public** — مطلوب لتشغيل الاستضافة المجانية.
5. اضغط **Create repository**.

## ثانيًا: رفع الملفات

1. في صفحة المستودع اضغط **Add file** ← **Upload files**.
2. اضغط **choose your files** واختر الملفات الستة كلها مرة واحدة.
3. انتظر اكتمال الرفع، ثم اضغط **Commit changes**.
4. تأكد أنك ترى `index.html` في قائمة الملفات مباشرة، وليس داخل مجلد.

## ثالثًا: تشغيل الاستضافة

1. **Settings** (أعلى الصفحة) ← **Pages** من القائمة الجانبية.
2. تحت *Source* اختر **Deploy from a branch**.
3. Branch: **main** والمجلد **/ (root)** ← **Save**.
4. انتظر دقيقة إلى دقيقتين وحدّث الصفحة، فيظهر الرابط:
   `https://اسم-حسابك.github.io/baksha/`

## رابعًا: التثبيت على أندرويد

1. افتح الرابط في متصفح **كروم** على الهاتف — لا من متصفح داخل واتساب أو فيسبوك.
2. اضغط **⋮** أعلى اليمين ← **تثبيت التطبيق** (أو *Install app* / *إضافة إلى الشاشة الرئيسية*).
   - يوجد أيضًا زر **تثبيت على الجهاز** داخل التطبيق في تبويب «البيانات».
3. تظهر الأيقونة على شاشة الهاتف ويفتح بملء الشاشة بلا شريط عناوين.
4. **افتحه مرة واحدة والإنترنت متصل** حتى يُخزَّن الخط ومكتبة PDF، وبعدها يعمل بالكامل بدون إنترنت.

---

## تحديث نسخة لاحقًا

1. ارفع `index.html` الجديد فوق القديم: **Add file → Upload files** ثم **Commit changes**.
2. افتح `sw.js` داخل المستودع ← أيقونة القلم ✏ ← غيّر:
   `const VERSION = 'baksha-v1'` إلى `'baksha-v2'` ← **Commit changes**.
3. أغلق التطبيق وافتحه مرتين ليأخذ التحديث.

بدون تغيير رقم `VERSION` سيظل الهاتف يفتح النسخة القديمة المخزّنة عنده.

---

## تنبيه عن البيانات

البيانات محفوظة داخل التطبيق على هذا الهاتف فقط:

- حذف التطبيق أو مسح بيانات كروم يمحو السجل كاملًا.
- لا تتزامن البيانات بين الهاتف والكمبيوتر أو بين هاتفين.
- **نزّل نسخة احتياطية دوريًا** من تبويب «البيانات» ← *تنزيل نسخة احتياطية*، واحفظ الملف على درايف أو أرسله لنفسك على واتساب.

## ملخص المميزات

- لوحة رئيسية بالأصول وأرصدة المخزن والمزارع والمبايع.
- رصيد افتتاحي للمخزن مقسوم إلى سليم وتالف.
- العمليات في أربعة تبويبات:
  - **صادر**: صرف عهدة · تالف للمصنع
  - **وارد**: توريد راجع · بديل من المصنع · شراء جديد
  - **تحويلات**: بيع سمك · تحويل فارغ
  - **تسويات**: جرد وتسوية للمزرعة والمبيع معًا
- **الجرد والتسوية**: ترجّع البكش سليمًا وتالفًا وتُدخل المتبقي عند الجهة، فيحسب التطبيق الفاقد وينبّهك به ويطلب تأكيدًا قبل خصمه.
- التالف الراجع من **المبيع** يُحتسب على السائق عند تحديد «إهمال سائق»، أما التالف الراجع من **المزرعة** فيُسجَّل «إهلاك بالمزرعة» ولا يُحتسب على السائق.
- تاريخ ووقت يدوي لكل حركة لتسجيل عمليات الأيام السابقة.
- تعديل أو إلغاء أي حركة مع حفظ السبب في **سجل التغييرات**.
- تقارير: يومية المخزن · كشف حساب جهة بمدة زمنية · لوحة مخاطر السائقين · كل الحركات ببحث وفلترة · سجل التغييرات.
- تصدير PDF وطباعة.
- نسخ احتياطي واستعادة بملف JSON.
